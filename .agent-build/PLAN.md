```text
                                      └─────────────┬─────────────┘
                                                    ▼
                                      P7 release [4·Exhaustive]
```

Graph validation:

- **Acyclic:** every edge moves from research to frozen specifications, foundation, implementation,
  and release.
- **Parallel outputs are disjoint:** P2 writes `safety.md` while P3 writes `design.md`; P5 owns
  server/shared engine packages while P6 owns `apps/web`.
- **Contracts freeze first:** P1 freezes APIs, state, evidence, job, and export contracts before
  parallel specs or build lanes.
- **Shared dependency files have one owner:** P4 owns root manifests and `pnpm-lock.yaml`. P5 and P6
  may not independently mutate them; missing dependencies route through the tech lead as a
  serialized integration change.
